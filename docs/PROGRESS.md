## Step 10 deliverables

- `tests/test_models_graph.py`: model contracts and graph construction invariants.
- `tests/test_algorithms.py`: coloring validity, empty graph, and bounded-search comparison.
- `tests/test_grid_constraints.py`: grid geometry, hard constraints, and soft-score smoke tests.
- `tests/test_reporting_cli.py`: smoke checks for reporting and CLI entry-point files.
- `scripts/check_imports.py`: AST-based check that reporting modules do not directly import graph/algorithm implementation packages.

Run from the project root:

```bash
python -m unittest discover -s tests -v
python scripts/check_imports.py
```
